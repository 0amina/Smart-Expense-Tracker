# Smart Expense Tracker

A MERN stack application designed to help students manage expenses and understand their spending habits.

## Project Structure

- `Front/` — Frontend application.
- `Back/` — Backend API.

## Tech Stack

- MongoDB
- Express.js
- React
- Node.js

## Features

Document the features implemented in the project, such as expense tracking, transaction management, budget monitoring, authentication, and spending visualizations.

## Getting Started

Install dependencies separately in the frontend and backend folders. Configure the required environment variables before running the application.
